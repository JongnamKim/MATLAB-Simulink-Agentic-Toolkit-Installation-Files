전체 흐름

외부망 PC에서 다운로드 App으로 자산을 수집하고 폐쇄망 PC로 반입한 뒤, Installer App으로 Offline=true 설치를 실행합니다.

1. 외부망에서 자동 수집

AgenticToolkitFilesDownloaderApp을 실행해 installer add-on, MCP server binary, MCP toolbox, MATLAB/Simulink Toolkit ZIP을 D:\agentic-offline에 다운로드하고 압축을 풉니다.

2. 폐쇄망으로 반입

다운로드 결과 폴더와 AgenticToolkitOfflineInstallerApp.m을 함께 반입하고 SHA-256 해시와 승인 기록을 보관합니다.

3. App에서 설치 및 검증

Installer App에서 Validate Files, Install Offline, Install Skills, Status / Initialize 순서로 확인합니다.

환경 선택

OS와 에이전트를 선택하면 참고용 수동 설치 명령과 binary 이름이 자동으로 바뀝니다.

AI Agent 설정

          
이 섹션은 Roo Code를 예시 Agent로 사용하여 설명합니다. 동일한 개념은 Codex, Copilot, Claude Code 등 다른 MCP 지원 Agent에도 적용할 수 있습니다.

        

        

          예시 구성 개념: Roo Code는 예시 Agent이며 LLM 자체가 아닙니다. 개인 PC의 Roo Code가 사내 API endpoint를 통해 Gemma 또는 Qwen 계열 내부 LLM에 요청을 보내고, 별도의 MCP 연결을 통해 로컬 MATLAB/Simulink 작업을 실행합니다. 외부 인터넷은 필요하지 않지만 개인 PC에서 내부 LLM endpoint로의 사내망 통신은 허용되어야 합니다.
        

        
중요: Roo Code는 본 문서의 설명을 위한 예시 Agent입니다. 고객 환경에서는 Codex, GitHub Copilot, Claude Code, Gemini CLI 또는 MCP를 지원하는 다른 Agent를 사용할 수 있습니다. 핵심 원리는 "Agent → 내부 LLM → MATLAB MCP Server → MATLAB/Simulink" 연결 구조입니다.

          
1. 내부 LLM
Gemma4 31B, Qwen3.6 등 사내 모델을 OpenAI-compatible API 또는 Roo Code가 지원하는 provider 방식으로 제공합니다.

          
2. Roo Code
사용자 목표를 해석하고 작업 순서를 계획합니다. Base URL, API Key, Model ID는 고객의 내부 LLM gateway 값으로 설정합니다.

          
3. MATLAB MCP
Roo Code의 tool call을 MATLAB session에 전달합니다. Simulink extension file을 함께 지정해야 Simulink 전용 tool이 노출됩니다.

        

        

          
폐쇄망 Agentic AI 연결 구조

          
개인 PC의 VS Code + Roo Code
        │
        ├── HTTPS/REST ──> 사내 LLM API Gateway
        │                  └── Gemma4 31B / Qwen3.6
        │
        └── local MCP ──> MATLAB MCP Server
                           └── MATLAB + Simulink Agentic Toolkit

문제 해결

          
증상별로 원인을 좁혀 확인합니다.

        

        

          
내부 LLM에 연결되지 않음 LLM API
Base URL, 정확한 Model ID, API Key, 내부 DNS, 방화벽 포트, TLS 인증서 신뢰 여부를 확인합니다. 브라우저 접속 가능 여부만으로 API 호출 성공을 판단하지 않습니다.

          
대화는 되지만 MATLAB tool이 보이지 않음 MCP
LLM 연결과 MCP 연결은 별개입니다. Roo Code MCP 설정의 binary 경로와 --extension-file 경로를 확인하고, MATLAB에서 satk_initialize를 실행한 뒤 Roo Code 세션을 다시 시작합니다.

          
다운로드 App에서 일부 파일 실패 network
외부망 PC에서 GitHub release와 archive URL 접근, 프록시, TLS 인증서, 방화벽 정책을 확인합니다. 실패한 항목은 App 로그의 파일명과 URL 기준으로 재시도하고, 완료 후 ZIP 압축 해제 폴더가 생성됐는지 확인합니다.

          
Installer App의 Validate Files 실패 files
반입 폴더 바로 아래에 agenticToolkitInstaller.mltbx, MATLABMCPServerToolbox.mltbx, matlab-mcp-server-windows-x64.exe, simulink-agentic-toolkit-main, 선택 시 matlab-agentic-toolkit-main이 있는지 확인합니다.

          
Add-On Manager가 열리지 않음 install
GUI 대신 MATLAB Command Window에서 installer add-on 설치 명령을 실행합니다. 예: matlab.addons.toolbox.installToolbox("agenticToolkitInstaller.mltbx")

          
satk_initialize를 찾지 못함 path
현재 MATLAB 세션에 toolkit 루트가 path로 추가되지 않은 상태입니다. 설치 후 addpath(...)를 다시 실행합니다.

          
에이전트가 Simulink 스킬을 보지 못함 skill
setupAgenticToolkit("configure")를 재실행하고 에이전트 세션을 재시작합니다. Codex, Gemini, Copilot은 일반적으로 ~/.agents/skills/ 링크를 사용합니다.

          
Codex on Windows에서 Simulink가 실패함 WINDIR
~/.codex/config.toml의 [mcp_servers.matlab]에 env_vars = ['WINDIR']를 추가합니다.

          
Codex tool call timeout timeout
MATLAB 초기화, 모델 컴파일, 시뮬레이션은 오래 걸릴 수 있습니다. tool_timeout_sec = 600 이상으로 조정합니다.

          
model_test만 실패함 Simulink Test
model_test는 Simulink Test가 필요합니다. 해당 제품이 없으면 다른 MCP 도구 중심으로 검증 범위를 조정합니다.
